Glomr is a static site builder in PHP that uses Blade templates from Laravel and features an asset pipeline that aggregates and compresses assets and allows for arbitrary complex site structures. Glomr is based on a library [glomr-lib](https://github.com/TedMoyses/glomr-lib) that can be extended to build many types of content into static HTML. Both of these are available on [Packagist](https://packagist.org/packages/tedmoyses/glomr)

This is, in truth quite an old project but did indeed serve it's twin purposes of learning while practicing code and faithfully rendering out this site for a number of years in the pre-AI age. This has since been replaced with [11ty](https://11ty.dev) as I no longer feel the need to have that level of control over exactly how my content is stored and rendered.

This project required a modest investment in used hardware to assemble a 3 node cluster and begin building a "production adjacent" cluster for the primary purpose of learning kubernetes hands on.

This project will actually be detailed in a series of posts on my blog as build out and configure the hardware then dive headlong into the world of the boatman.

Typically when learning a new platform or technology I would tend to reach for a combination of tutorial videos to undertand the basics and reference documentation. For this project I decided instead to lean heavily on AI agents to build my knowledge - how far and how fast can I accelerate my understanding of the industry standard container orchestration platform?

So far I have used an AI agent almost entirely with only a handful of web searches required for filling in gaps or correcting an issue. This is proving to be an interesting journey!
